## Ideas and results we rely on

| Idea | Source | Where QED uses it |
|---|---|---|
| Certifying algorithms (a simple checker validates a witness) | McConnell, Mehlhorn, Näher, Schweitzer, *Computer Science Review* 5(2), 2011 | the whole design |
| KKT conditions; weak and strong Lagrangian duality | standard (Boyd & Vandenberghe, *Convex Optimization*, 2004) | §4, §9, §12 |
| Optimal routing through CFMMs is convex; its dual decomposition | Angeris, Agrawal, Evans, Chitra, Boyd, *Optimal Routing for Constant Function Market Makers*, EC 2022 | §12 (strong duality, completeness) |
| Path deficiency of fee-charging CFMMs | Angeris & Chitra, *Improved Price Oracles: Constant Function Market Makers*, AFT 2020 | §12.3 |
| Uniswap V2 pair interface and constant-product invariant with fee | Uniswap V2 core (Adams, Zinsmeister, Robinson, 2020) | `CPMMPool` follows the interface; no Uniswap code is copied |
| Minimum-mean cycle cancelling; minimum-mean cycle | Goldberg & Tarjan, 1989; Karp, 1978 | `agent/src/engine/netting.ts` |
| Multilateral trade-credit set-off | Fleischman & Dini, 2021; Cycles Protocol (Buchman et al.) | the clearing problem (§9) |
| SNARKs for optimality certificates | Angel, Blumberg, Ioannidis, Woods, *Otti*, USENIX Security 2022 | §10 |
| Groth16 | Groth, EUROCRYPT 2016 | §10 |
| Poseidon hash | Grassi, Khovratovich, Rechberger, Roy, Schofnegger, USENIX Security 2021 | §10 |
| Self-adjudicating refutation bounties | Peter Todd's hash-collision bounties, 2013 | §11 |
| Separating language understanding from control of money | CaMeL, Debenedetti et al., 2025; dual-LLM pattern | §8 |

Full comparisons are in `docs/PRIOR_ART.md`.
