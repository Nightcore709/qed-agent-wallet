# Third-party source carried beside the vendored release

`vendor/` is the October release copied byte for byte and pinned by `VENDORED.json` (the wallet service refuses to start
if a vendored file changes), so notices and sources that the vendored tree lacks are kept here instead.

| File | Licence | Why it is here |
|---|---|---|
| `Groth16Verifier.sol` | GPL-3.0 (its own header; generated by snarkjs 0.7.5, Copyright 2021 0KIMS association) | `vendor/agent/src/abi/contracts.ts` carries this verifier's compiled bytecode (`Groth16VerifierBytecode`), used only by the optional ZK tier (`zk-optional/`, off by default). This is its corresponding source, verbatim from the release's `contracts/src/verifiers/zk/` (SHA-256 identical). It is not compiled by this tree's build. |

QED's own code is MIT (`vendor/LICENSE`); the other third-party components and their licences are listed in
`vendor/ATTRIBUTIONS.md`. Licence notes for the ZK tier: `docs/research/qed-engineer/20261125-r14-zk-parity.md` (not legal advice).
