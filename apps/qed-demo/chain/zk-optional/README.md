# zk-optional: the zero-knowledge paid-work scenario (off by default)

Parity row **F-052**. The release proves, with a Groth16 proof, that a portfolio is the minimum-variance optimum
for a covariance matrix that never leaves the prover (baseline M-28). On the rail this is the `private_portfolio`
scenario and the `privacy` scripted economy.

It is **not part of the default build**, for three reasons the owner has not yet decided on:

- **Licence.** It needs snarkjs 0.7.5 and circomlibjs 0.1.7 (GPL-3.0), the circuit `private_minvar.circom`, which
  includes circomlib templates (GPL-3.0), and `Groth16Verifier.sol`, generated by snarkjs from its GPL-3.0 template.
  The default package installs none of these and `vendor/` holds none of these files.
- **Trusted setup.** The proving key comes from a single-machine ceremony (the release's own disclosure, K-list in
  `docs/SECURITY.md`). A proof is only as trustworthy as that setup.
- **Weight.** About 10.6 MB of artefacts and a prover that takes seconds per proof.

One thing the default build does contain: `vendor/agent/src/abi/contracts.ts` is the release's fingerprinted file
with the bytecode of all fifteen contracts, including the Groth16 verifier compiled from that GPL-3.0 source. The
default rail never deploys it. Removing it would break "unmodified"; whether its presence matters is part of F-052.

## What is here

| File | Committed | What it is |
|---|---|---|
| `VENDORED-ZK.json` | yes | the 17 files of this tier with source path and SHA-256 (11 of them are fingerprinted runtime files of the release). Hashes only, no content |
| `package.json`, `package-lock.json` | yes | exact pins (snarkjs 0.7.5, circomlibjs 0.1.7 and 81 transitive packages), cut from the release's lockfile with identical versions and integrity hashes; 11 of the 83 are GPL-3.0 |
| `enable.mjs` | yes | copies the 17 files out of the approved release (read-only), verifying each hash |
| `vendor/`, `node_modules/`, `.build/` | **no** (git-ignored) | exist only after you enable the tier |

## Enable, use, disable

```bash
cd apps/qed-demo/chain
node zk-optional/enable.mjs --accept-gpl-3.0      # copies 17 files, verifies every SHA-256; installs nothing
(cd zk-optional && npm ci --ignore-scripts)       # snarkjs and circomlibjs; no install script runs
node zk-optional/enable.mjs --status              # {"enabled": true, …}

QED_RAIL_ZK=1 node serve.ts                       # the rail now offers private_portfolio and the privacy economy
node scripts/parity-gate.mjs --tier full          # the release's complete suites, including the 27 tests of this tier

node zk-optional/enable.mjs --disable && rm -rf zk-optional/node_modules     # back to the default
```

With `QED_RAIL_ZK=1` the rail loads the release from `zk-optional/.build/tree/`, a copy assembled from `vendor/`
plus `zk-optional/vendor/` and checked against both manifests at every start. Without the flag nothing in this
folder is read. A fresh data folder is not required: the scenario deploys its own verifier per run.

`GET /scenarios` reports `private_portfolio` as `available: false` with the reason until then, and a proposal for
it, or a `privacy` run, is refused with `409 zk_optional_disabled`.
